## hatin
A&I 2기 1팀의 미니 프로젝트입니다!

## 👨‍🏫 프로젝트 소개
hatin은 **'하'루루'틴'**의 줄임말로, 생활 패턴을 추천해 주는 비서 역할을 합니다.

## ⏲️ 개발 기간
개발 기간: 2024년 6월 22일 ~ 2024년 7월 31일
Back-End Repository입니다.

## 📌 주요 기능
- 사용자의 생활 패턴을 분석하여 맞춤 루틴 추천
- 일정 및 루틴 관리 기능 제공
- 사용자의 피드백을 반영하여 추천 최적화
